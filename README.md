# Honda Strategy Simulator

Dash / Plotly を利用した中長期戦略シミュレータアプリです。

## セットアップ手順

1. リポジトリをクローンします。
```bash
git clone <your-repository-url>
cd honda-strategy-sim
```

2. 必要なライブラリをインストールします。
```bash
pip install -r requirements.txt
```

3. アプリを起動します。
```bash
python app.py
```

4. ブラウザで http://127.0.0.1:8050/ にアクセスしてシミュレータを利用します。
